# 📖 About the Project

Employees Salary Prediction is a Machine Learning application that estimates an employee's annual salary based on professional experience and performance rating.

The project follows the complete Machine Learning workflow, including data preprocessing, model training, evaluation, and deployment through a Streamlit web application.


# ✨ Key Features

- 📊 Salary prediction using Machine Learning
- ⚡ Fast and accurate predictions
- 🎯 Interactive Streamlit interface
- 📁 Excel dataset support
- 💾 Pre-trained model using Joblib
- 🌐 Ready for cloud deployment
